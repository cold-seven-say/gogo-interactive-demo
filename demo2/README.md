# Gogo Demo2

独立于 `gogo-interactive-demo`（Demo1）的 H5 可交互原型。直接打开 `index.html` 即可运行，无需构建或网络服务。页面中的品牌、账户金额、中奖、比赛、游戏与活动信息均为演示数据，不是已批准的运营规则。

页面：Home、分类 View All、Promo、Race、Cricket、个人中心抽屉、个人资料与编辑、登录、Footer 内容页。按钮、标题、表格、账户数据等由 HTML 文本渲染；插画和图标为资源文件或内联 SVG。

## 项目区分

- 未明确指定或称 Demo1：`gogo-interactive-demo`
- 明确称新项目或 Demo2：`gogo-interactive-demo2`

该约定用于后续修改范围，不允许将 Demo2 改动自动写入 Demo1。
